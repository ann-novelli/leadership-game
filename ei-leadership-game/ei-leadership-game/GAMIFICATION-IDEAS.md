## 🎲 Board Game Mechanics

### **Concept: "The Leadership Journey"**

Transform the game into a visual journey with these elements:

#### **Game Board Layout**
```
START → [Scenario 1] → [Scenario 2] → [Scenario 3] → [Scenario 4]
          ↓              ↓              ↓              ↓
      [EI Badge]     [EI Badge]     [EI Badge]     [EI Badge]
          ↓              ↓              ↓              ↓
    [Scenario 5] → [Scenario 6] → [Scenario 7] → [Scenario 8] → FINISH
          ↓              ↓              ↓              ↓
      [EI Badge]     [EI Badge]     [EI Badge]     [EI Badge]
```

#### **Visual Elements**
- **Path tiles**: Each scenario is a tile on the board
- **Player tokens**: Avatars move along the path
- **EI badges**: Collect badges for strong responses
- **Progress bar**: Visual indicator of game completion

## 🎯 Scoring Enhancements

### **Point System**
- **Base points**: For each response
- **Speed bonus**: +5 for quick responses
- **Consistency bonus**: +10 for all positive scores
- **Discussion bonus**: +5 for active participation
- **Badge bonus**: +20 per badge earned

### **Level System**
Players level up based on total points:
- Level 1: Emerging Leader (0-50 points)
- Level 2: Developing Leader (51-100 points)
- Level 3: Skilled Leader (101-150 points)
- Level 4: Expert Leader (151-200 points)
- Level 5: Master Leader (201+ points)

### **Combo System**
- **3 in a row**: Same EI component → "Specialist!"
- **All positive**: All scenarios positive → "Consistent!"
- **Perfect round**: Highest score in scenario → "Star!"

## 🚀 Quick Implementation Guide

### **Step 1: Add Player Colors**
In `ui.js`, assign colors when players join:
```javascript
const playerColors = ['#4A90E2', '#7ED321', '#F5A623', '#BD10E0', '#E24A4A'];
player.color = playerColors[index % playerColors.length];
```

### **Step 2: Add Progress Visualization**
Create a progress bar component showing scenario completion.

### **Step 3: Add Sound Effects**
Use Web Audio API or simple audio files:
```javascript
const joinSound = new Audio('/sounds/join.mp3');
joinSound.play();
```

### **Step 4: Add Badges**
Track achievements in player object and display earned badges.
